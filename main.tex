\subsection{Foundations of Fractal Image Compression}
The theoretical framework of Fractal Image Compression (FIC) originates from the application of the fractal transform via Iterated Function Systems (IFS) \cite{Barnsley1985}. This mathematical foundation utilizes the Collage Theorem and the Contractive Mapping Fixed-Point Theorem to systematically exploit block self-affine redundancies inherent within digital images \cite{barnsley2014fractals, Barnsley1985}. Early implementations demonstrated the feasibility of compressing images through these multi-scale fractal mapping principles \cite{barnsley1988better}, which ultimately led to the development of automated, block-based practical compression schemes \cite{FICOriginal}.

In the standardized block-oriented framework, encoding a gray-level image of size $N \times N$ requires partitioning the spatial domain into a range pool $R$ comprised of $(N/L)^2$ non-overlapping range blocks $v$ of dimensions $L \times L$ \cite{FICOriginal}. Concurrently, a domain pool $D$ is established by extracting $(N - 2L + 1)^2$ overlapping domain blocks of size $2L \times 2L$ \cite{FICOriginal}. For each distinct range block $v \in R$, a search is executed across the virtual codebook of the domain pool to map a contractive affine transformation $\Phi$ from the domain to the range block space \cite{FICOriginal}.

To evaluate similarity metrics, each candidate domain block $u$ is down-sampled to match the $L \times L$ resolution of the target range block. Spatial orientation constraints are handled by subjecting the down-sampled domain block to eight canonical Dihedral transformations (isometries) $T_k$ ($k = 0, 1, \dots, 7$), producing an array of transformed domain blocks $u_k$, where $u_0 = u$ \cite{FICOriginal}. These geometric operations include horizontal reflection ($T_1$), vertical reflection ($T_2$), combined horizontal-vertical reflection ($T_3$), and diagonal reflections ($T_4$ through $T_7$).

The discrete block-wise contractive affine transformation $\Phi$ consists of a spatial (geometric) mapping and a massic (intensity) mapping. The spatial transformation maps the coordinates of the domain block to the range block:
\begin{equation}
W_k \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} + \begin{bmatrix} t_x \\ t_y \end{bmatrix},
\end{equation}
where the $2 \times 2$ sub-matrix represents the Dihedral transformation operator $T_k$, and $(t_x, t_y)$ establishes the spatial offset of the matching domain block. 

Concurrently, the massic transformation adjusts the pixel intensities $z = u(x,y)$ of the mapped domain block:
\begin{equation}
\Phi(z) = p \cdot z + q,
\end{equation}
where $p$ defines the contrast scaling factor ($\alpha$), and $q$ denotes the brightness offset ($\Delta g$) \cite{FICOriginal}.

Parameter optimization is modeled as an inverse problem minimized using a Mean Squared Error (MSE) or Peak Signal-to-Noise Ratio (PSNR) distortion metric \cite{FICOriginal}. For each pairing, the specific isometry index $d$ is determined via:
\begin{equation}
d = \arg\min_{k \in \{0,1,\dots,7\}} \left\{ \text{MSE}(v, p_k u_k + q_k) \right\},
\end{equation}
where the discrete MSE over an $L \times L$ pixel grid is computed as:
\begin{equation}
\text{MSE}(v, u) = \frac{1}{L^2} \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} \left( v(i,j) - u(i,j) \right)^2.
\end{equation}
Applying least-squares regression to minimize this distortion objective yields closed-form solutions for the mass parameters $p$ and $q$:
\begin{equation}
p = \frac{N_p}{D_p},
\end{equation}
where the numerator $N_p$ and denominator $D_p$ are defined as:
\begin{equation}
\begin{split}
N_p &= L^2 \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} v(i,j) u_k(i,j) \\
&\quad - \left( \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} v(i,j) \right) \left( \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} u_k(i,j) \right),
\end{split}
\end{equation}
\begin{equation}
D_p = L^2 \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} u_k(i,j)^2 - \left( \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} u_k(i,j) \right)^2.
\end{equation}
\begin{equation}
q = \frac{1}{L^2} \left[ \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} v(i,j) - p \sum_{i=0}^{L-1} \sum_{j=0}^{L-1} u_k(i,j) \right].
\end{equation}

The resulting code vectors—comprising spatial coordinates $(t_x, t_y)$, orientation index $d$, scale factor $p$, and offset $q$—are uniformly quantized and bit-allocated for transmission. Image reconstruction at the decoder operates recursively by applying these mapped transformations onto an arbitrary initial image profile. Based on the Partitioned Iteration Function System (PIFS) model and Banach's fixed-point theorem, the processing sequence yields a convergent Cauchy sequence that terminates at a unique invariant attractor image.

\subsection{Acceleration Techniques in FIC}
Although capable of guaranteeing high compression ratios and reconstruction fidelity, conventional FIC is constrained by an exhaustive search strategy \cite{241507}. Because each independent range block must iterate through every permutation of domain blocks across all eight orientations, the computational overhead is exceedingly high, limiting real-time practical utility \cite{241507}.

To bypass this computational bottleneck, subsequent literature has introduced alternative structural paradigms. Range block search spaces have been constrained through quad-tree partitioning topologies \cite{compression1995fractal} and hierarchical tree-structured block classification methods \cite{478245, hurtgen1993fast} to group blocks by geometric or statistical features. Concurrently, parallel processing arrays and custom hardware engine architectures have been leveraged to distribute matching operations across distinct Single Instruction, Multiple Data (SIMD) hardware elements \cite{hufnagl2000algorithms, vidya2000architecture}. However, to fundamentally reduce the combinatorial complexity of the search space itself, modern approaches increasingly rely on stochastic optimization.

\subsection{Metaheuristic Optimization Frameworks in FIC}
To mitigate the exponential computational complexity inherent in exhaustive block-matching, stochastic metaheuristics—particularly swarm-based architectures—are widely integrated into the FIC pipeline \cite{241507, PSOFIC}. By encoding the structural parameters of the fractal mapping into mathematical optimization arrays, the exhaustive scan is re-engineered into an intelligence-driven localization problem.

\subsubsection{Particle Swarm Optimization (PSO) in FIC}
Standard Particle Swarm Optimization (PSO) is a population-based optimization methodology modeled after biological swarm intelligence \cite{PSOOriginal, eberhart1995new}. The algorithm structures a swarm of candidate solutions, termed particles, utilizing a time-varying position vector $\mathbf{X}_i = (x_{i1}, x_{i2}, \dots, x_{iD})$ and a corresponding trajectory velocity vector $\mathbf{V}_i = (v_{i1}, v_{i2}, \dots, v_{iD})$. Particles navigate by balancing localized personal discovery ($\mathbf{P}_{\text{BEST}, i}$) with global collective information propagation ($\mathbf{G}_{\text{BEST}}$) \cite{PSOOriginal}. At each generation step $t$, updates are formulated as:
\begin{equation}
\begin{split}
\mathbf{V}_i(t+1) &= w \cdot \mathbf{V}_i(t) + c_1 \cdot r_1 \cdot (\mathbf{P}_{\text{BEST}, i} - \mathbf{X}_i(t)) \\
&\quad + c_2 \cdot r_2 \cdot (\mathbf{G}_{\text{BEST}} - \mathbf{X}_i(t)),
\end{split}
\end{equation}
\begin{equation}
\mathbf{X}_i(t+1) = \mathbf{X}_i(t) + \mathbf{V}_i(t+1).
\end{equation}

When mapped onto the discrete FIC domain, each particle $\mathbf{X}_i$ represents a candidate contractive transformation vector, defining the discrete spatial offset location $(t_x, t_y)$ of a domain block, the orientation index $d$, and the mass parameters $p$ and $q$ \cite{FICOriginal, PSOFIC}. While standard PSO achieves order-of-magnitude acceleration compared to exhaustive search, its reliance on a single global best exemplar ($\mathbf{G}_{\text{BEST}}$) often causes premature convergence within the complex, highly multimodal fitness landscapes of image domain pools, occasionally leading to sub-optimal block matching and degraded reconstruction quality.

\subsubsection{Pyramid Particle Swarm Optimization (PPSO)}
To mitigate the premature stagnation behavior of canonical PSO, Pyramid Particle Swarm Optimization (PPSO) replaces the single-exemplar topology with a hierarchical, multi-exemplar search architecture \cite{li2022pyramid}. At each iteration, the particle population is sorted according to fitness and partitioned into a finite set of pyramid tiers, ranging from a small elite tier at the apex to a larger exploratory tier at the base. Let $\mathcal{L}_1, \mathcal{L}_2, \dots, \mathcal{L}_H$ denote these tiers ordered from top to bottom, where particles in $\mathcal{L}_1$ have the best current fitness values.

Within each tier, particles are randomly paired and subjected to pairwise competition. For a pair $(i,j)$ in the same tier, the particle with lower distortion is designated the \emph{winner} and the other the \emph{loser}. The loser updates its trajectory by learning from the winner within the same tier, whereas the winner learns from an exemplar sampled from the immediately superior tier and from an exemplar sampled from the elite tier \cite{li2022pyramid}. In a generic form, the loser update is written as
\begin{equation}
\mathbf{V}_{\ell}(t+1)=w\mathbf{V}_{\ell}(t)+c_1r_1\left(\mathbf{X}_{w}(t)-\mathbf{X}_{\ell}(t)\right),
\end{equation}
where $\ell$ and $w$ denote the loser and winner, respectively. For a winner particle, the update incorporates both a higher-tier exemplar $\mathbf{X}_{u}$ and a top-tier elite exemplar $\mathbf{X}_{e}$:
\begin{equation}
\mathbf{V}_{w}(t+1)=w\mathbf{V}_{w}(t)+c_1r_1\left(\mathbf{X}_{u}(t)-\mathbf{X}_{w}(t)\right)+c_2r_2\left(\mathbf{X}_{e}(t)-\mathbf{X}_{w}(t)\right).
\end{equation}
The particle position is then advanced by
\begin{equation}
\mathbf{X}(t+1)=\mathbf{X}(t)+\mathbf{V}(t+1).
\end{equation}

This competition-cooperation mechanism induces a stratified search dynamic: upper tiers emphasize exploitation around already promising regions, while lower tiers preserve broader exploration. For the FIC block-matching problem, where the search space over domain indices and geometric transforms is highly multimodal and discrete after decoding, such a multi-leader topology is particularly advantageous. It reduces the risk that the entire swarm collapses prematurely toward a single sub-optimal attractor and thereby improves the probability of locating higher-quality domain-range correspondences.

\subsubsection{Memetic Algorithms (MAs) and Local Search Integration}
While PPSO provides a stronger global search mechanism than standard PSO, swarm-based updates alone still lack the deterministic, fine-grained exploitative accuracy required for precise block matching in FIC. Memetic Algorithms (MAs) address this exploration-exploitation imbalance by embedding explicit Local Search (LS) operators into the global search loop. 

Mathematically, let $\mathcal{X}$ denote the discrete optimization domain of feasible code vectors, and let $f: \mathcal{X} \rightarrow \mathbb{R}$ be the distortion objective defined by the block-wise MSE \cite{FICOriginal}. The PPSO stage generates a candidate solution $x \in \mathcal{X}$, after which a memetic refinement operator $\Lambda: \mathcal{X} \rightarrow \mathcal{X}$ is applied within a local neighborhood of $x$, enforcing monotonic improvement:
\begin{equation}
f(\Lambda(x)) \le f(x).
\end{equation}
In the present framework, the memetic component is not introduced as an independent genetic stage; rather, it functions as a deterministic refinement layer coupled to the PPSO search. Specifically, after periodic PPSO updates, LS is applied to the top-performing subset of particles, and an additional terminal LS pass is imposed on the final global best solution. The refinement stage is composed of two sequential operators.

The first operator is an \emph{isometry refinement} procedure. Let the current candidate be $x=(d,k)$, where $d$ denotes the selected domain index and $k$ denotes the geometric transformation index. Holding $d$ fixed, the operator evaluates the complete admissible transform set $\mathcal{K}=\{0,1,\dots,7\}$ and computes
\begin{equation}
k^{*}=\arg\min_{k \in \mathcal{K}} f(d,k).
\end{equation}
The refined solution is then updated from $(d,k)$ to $(d,k^{*})$. Hence, this operator performs an exact local optimization over the discrete transformation subspace and corrects mismatches introduced by the continuous-to-discrete decoding of particle states.

The second operator is a \emph{spatial neighborhood refinement} procedure. Let $\mathcal{N}(d)$ denote the set of domain blocks located in the immediate spatial neighborhood of the current domain block, typically defined by adjacent positions under the domain sampling stride. With the refined transform index $k^{*}$ held fixed, the operator solves
\begin{equation}
d^{*}=\arg\min_{d' \in \mathcal{N}(d)} f(d',k^{*}),
\end{equation}
thereby replacing the current domain assignment with the best local spatial neighbor whenever an improvement is obtained. This step exploits the empirical continuity of image self-similarity, namely that domain blocks spatially adjacent to a promising candidate frequently provide lower-distortion correspondences for the same range block.

Whenever either refinement step yields a lower distortion, the improved solution is written back to the current particle state, namely its decoded position and associated fitness value, after which the global best record is updated if necessary. In this sense, the memetic layer acts as a problem-specific exploitation operator that complements the coarse-grained routing behavior of PPSO with exact discrete transform correction and local coordinate adjustment.

Accordingly, the proposed memetic mechanism serves as a domain-specific exploitation module that complements the global routing behavior of PPSO. PPSO first directs particles toward promising regions of the codebook, whereas the memetic layer subsequently performs discrete transform correction and local coordinate refinement. This division of labor yields a more stable balance between global exploration and local precision, which is critical for obtaining high-quality fractal codes under restricted evaluation budgets.
